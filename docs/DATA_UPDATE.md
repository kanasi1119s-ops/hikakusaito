# データ更新手順（DATA_UPDATE.md）

比較データはすべて `src/data/plans.json` という1つのファイルにまとまっています。専門知識がなくても、以下の手順でテキストエディタから更新できます。

## 手順（具体例: ChatGPT Plusの月額料金を$22に変更する場合）

1. `src/data/plans.json` をテキストエディタ（VS Code など）で開きます。
2. `"id": "chatgpt-plus"` を探します（Ctrl+F / Cmd+F で検索すると早いです）。
3. その中の `"priceMonthlyUsd": 20` を `"priceMonthlyUsd": 22` に書き換えます。
4. 同じブロック内の `"checkedAt": "2026-09-23"` を、確認した日付（例: `"2026-10-01"`）に書き換えます。
5. `"note"` の内容も、確認した経緯が分かるように書き換えます（例: 「2026年10月1日に公式サイトで再確認」）。
6. ターミナルで以下を実行し、データの形式が正しいか確認します。

   ```bash
   npm test
   ```

   ここでエラーが出た場合は、カンマの付け忘れやクォート（`"`）の閉じ忘れなど、JSONの書き方に誤りがある可能性があります。

7. `npm run build` を実行してビルドが通ることを確認します。
8. 問題がなければ、以下のようにコミットします。

   ```bash
   git add src/data/plans.json
   git commit -m "data: ChatGPT Plusの月額料金を更新"
   git push
   ```

## 新しいプランを追加する場合

`plans` 配列の末尾に、既存のプランと同じ形式（同じキーをすべて持つオブジェクト）を1件追加してください。`id` は他のプランと重複しない英数字・ハイフンの文字列にします（例: `"new-service-plan"`）。必須項目（`sourceUrl`・`checkedAt`・`note` を含む全項目）が1つでも欠けていると、`npm test` が失敗するようになっています。

## 90日ルール

各プランの `checkedAt` が今日から90日以上前になっている場合、CI（自動チェック）が警告を出します（ビルド自体は失敗しません）。警告が出たプランは、公式サイトで最新情報を確認し、`checkedAt` を更新してください。

## 注意事項

- 分からない項目・確認できなかった項目は、推測で数値を入れず `null` のままにしてください。画面には「—（未確認）」と表示されます。
- 金額は税抜・米ドル表記で統一しています。別の通貨や税込表記に変える場合は、`docs/DESIGN.md` の前提も合わせて見直してください。
- 秘密情報（APIキーなど）は、このファイルにも他のどのファイルにも書き込まないでください。
