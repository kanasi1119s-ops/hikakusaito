# 公開手順書（RELEASE.md）

このドキュメントは、本サイトを実際に公開する際に**人間が実行する**手順です。運用指示書の安全装置により、以下の作業はAIオーケストレーターが自動実行することを禁止されています。

## 前提

- リポジトリは現在 **private** です。
- 本サイトは静的サイト（W1）で、サーバー・データベース・環境変数は不要です。
- `npm run build` で生成される `dist/` フォルダがそのまま公開物です。

## 公開までのチェックリスト

1. **比較データの最終目視確認**（特に料金）
   - `docs/DATA_SOURCES.md` の出典URLを一つずつ開き、`src/data/plans.json` の値と一致しているか確認してください。
   - 特に「検索エンジン経由（直接アクセス不可）」と記載されている9プランは、このセッションでは公式ページへの直接アクセスができなかったため、優先的に確認してください。
   - 90日以上経過したデータがあれば更新してください（`docs/DATA_UPDATE.md` 参照）。

2. **リポジトリの public 化の判断**
   - GitHubリポジトリの Settings > General > Danger Zone から変更できます。

3. **静的ホスティングの有効化**（いずれか）
   - GitHub Pages: Settings > Pages で有効化。`.github/workflows/ci.yml` にPages用のデプロイジョブは含まれていないため、有効化する場合は別途 `actions/deploy-pages` 等を使ったワークフローの追加が必要です。
   - Cloudflare Pages / Netlify / Vercel 等: 各サービスにリポジトリを接続し、ビルドコマンド `npm run build`、公開ディレクトリ `dist` を指定してください。

4. **アフィリエイトを実施する場合**
   - 各社ASP（A8.net等）への登録・提携申請を行ってください（本サイトは未提携）。
   - 提携後、`src/data/plans.json` の各プランに `sourceUrl` とは別のアフィリエイトリンク用フィールドを追加し、`AXES` や表示コンポーネントにリンクと「PR」表記を実装する改修が必要です（現状のMVPにはプレースホルダーも未実装のため、追加の開発作業が発生します）。

5. **プライバシーポリシー・利用規約・免責事項・特定商取引法表記の最終確認**
   - `docs/legal/CHECKLIST.md` の内容と、サイト内「このサイトについて」ページの文言を、必要に応じて法律の専門家に確認してください。

6. **ドメイン取得**（独自ドメインを使う場合）
   - 取得後、ホスティングサービス側でDNS設定を行ってください。

7. **公開後の運用**
   - `docs/DATA_UPDATE.md` の手順で定期的にデータを更新してください。
   - CI（`.github/workflows/ci.yml`）がpushのたびに lint・型チェック・テスト・ビルド・データ鮮度チェックを実行します。

## ロールバック

静的サイトのため、ホスティング側の「以前のデプロイに戻す」機能、またはGitのコミットを戻して再デプロイすることで対応できます。
